Course Syllabus

PBCST404 – Computer Organization and Architecture

Semester S44 CreditsTheoryExam: 2 Hrs. 30 Min.

Course Objectives

  1. Introduce principles of computer organization and the basic architectural concepts using RISC.
  2. Introduce the concepts of microarchitecture, memory systems, and I/O systems.

Module 1 – Basic Structure and RISC Architecture 11 Hours

  • Basic structure of computers: functional units, basic operational concepts, memory map and endianness.
  • CISC vs RISC architectures; RISC introduction; assembly language, assembler directives and assembling.
  • Programming concepts: program flow, branching, conditional statements, loops, arrays and function calls.
  • Instruction execution cycle; machine language, instructions, addressing modes and stored-program concept.
  • Evolution of the RISC architecture.

Module 2 – Microarchitecture 11 Hours

  • Introduction to microarchitecture and performance analysis.
  • Single-cycle processor: single-cycle datapath and single-cycle control.
  • Pipelined processor: pipelined datapath and pipelined control.
  • Hazards; solving data and control hazards; performance analysis.

Module 3 – Memory Systems 11 Hours

  • Introduction to memory systems and performance analysis.
  • Caches: basic concepts, cache mapping, cache replacement and multiple-level caches.
  • Reducing miss rate and write policy.
  • Virtual memory: address translation, page table, translation lookaside buffer (TLB) and memory protection.

Module 4 – Input/Output Systems 11 Hours

  • Input/output: external devices and I/O modules.
  • Programmed I/O, interrupt-driven I/O and direct memory access (DMA).
  • Embedded I/O systems: embedded I/O, general-purpose I/O, serial I/O and other peripherals.
