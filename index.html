Course Overview

Computer Organization and Architecture (PBCST404) introduces the fundamental principles underlying the structure and operation of computer systems. The course uses RISC architecture to explain instruction sets, assembly-language programming, processor datapaths, pipelining, memory organization and input/output systems.

Students explore how hardware components work together to execute programs, how processor performance is analysed, and how memory and I/O mechanisms affect the overall operation of a computer system.

Course Objectives

  1. Introduce principles of computer organization and the basic architectural concepts using RISC.
  2. Introduce the concepts of microarchitecture, memory systems, and I/O systems.

What You Will Study

Module 1

Basic computer structure, RISC, assembly language and instruction execution.

11 Contact Hours

Module 2

Microarchitecture, single-cycle processors, pipelining and hazards.

11 Contact Hours

Module 3

Memory systems, cache organization and virtual memory.

11 Contact Hours

Module 4

Input/output organization, interrupts, DMA and embedded I/O.

11 Contact Hours
