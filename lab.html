Project and Simulation Tools

The syllabus suggests using computer-system simulators to implement and study components of computer systems.

ToolPurpose / Suggested UseWebsite
RipesRISC-V processor and assembly-level simulation; useful for exploring datapaths, instruction execution and pipeline behaviour.Ripes – GitHub
gem5Computer-system architecture simulator; can be used to study cache organization and other system components.gem5 – Official Website

Suggested Project Areas from the Syllabus

  • Implementing and comparing different cache organizations.
  • Studying the effect of cache design choices.
  • Exploring solutions to processor hazards.
  • Investigating translation lookaside buffers (TLBs).
